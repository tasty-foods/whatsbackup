THE BASICS

What it does.

What does WhatsBackUp actually save?

WhatsApp photos, videos and message text, with optional documents, voice notes, audio and stickers. You can also import uploaded and generated images from ChatGPT, and generated images from Gemini’s Library. Each source is linked separately.

Is it free? Do I need an AI subscription?

The desktop app is free. You do not need an AI subscription to save or browse your archive. Optional AI sorting uses your own provider API key; provider charges and limits apply. Review the estimate and set a monthly budget before sorting.

Does it replace WhatsApp’s phone backup?

No. It creates a browsable archive of files and messages on your PC. It does not restore a WhatsApp account or move your chat history to a new phone. Keep your normal phone backup for that.

Can it recover old or deleted pictures?

Import history can collect media that is still available in your linked chats. It cannot recover files that are no longer available from WhatsApp. Skipped and failed items appear in the import summary.

Does my computer need to stay on?

Yes. Capture, imports and scheduled statuses run while the app is running and the required services are reachable. Let it start with Windows if you want it ready in the background.

YOUR SOURCES

Connect, import and keep going.

How do I connect WhatsApp?

Scan the QR code using WhatsApp’s Linked devices menu on your phone. The app saves enabled media types and message text while it is running. You can exclude chats or change which media types are captured in Settings.

What is imported from ChatGPT and Gemini?

ChatGPT imports uploaded and generated images from your conversations. Gemini imports generated images from its Library. These are image sources, not a full export of every feature or every item in those services.

How do those accounts stay signed in?

Each source uses its own browser profile inside the app’s data folder. You sign in on the service’s own page. Keep these profiles private: they hold active sessions. Forgetting a source removes its saved browser profile; already archived files remain.

Why does an import pause or skip files?

Files may be unavailable, the source may require sign-in again, or the service may limit requests. The app reports progress and the import result. ChatGPT imports include retries and backoff for temporary failures. A retry cannot recover media the source no longer provides.

Can I use source filters?

Yes. Source filters help separate WhatsApp, ChatGPT and Gemini items while keeping them in the same archive. The overview also shows source-specific state and actions.

What happens if a service changes its website?

A change can interrupt linking or importing. Check the source status, update the app and report a persistent error. No tool using these unofficial connections can guarantee uninterrupted access.

OPTIONAL TOOLS

Organisation, copies and posting.

What does AI sorting do?

It labels images, groups them into albums and organises conversations into projects. Search can use the labels and text recognised in images. You can rename albums and correct placement; later sorting respects those edits.

What does AI cost?

The app is free; your provider may charge for API use. Rates, model capabilities and free-tier limits vary. The app offers an estimate, a monthly budget and provider connection checks. Configure suitable fallback providers if you want retries across providers.

Can I try the organisation view without sending content to a provider?

Demo mode creates sample labels locally without a provider key. It demonstrates the organisation workflow; it is not real AI analysis of your pictures.

What does “verified” mean for a cloud copy?

It means the file was present in the configured destination with a matching size when checked. It is not a full-content hash check or confirmation that a cloud service finished uploading it. Checks expire; run a fresh one after changes. Message data stays in the local database.

How do cleanup suggestions work?

The app flags possible duplicates using file size and a partial fingerprint, and can suggest small images. Review before acting: similar candidates may be different files. Move unwanted items to quarantine for a reversible cleanup. Permanent deletion is separate.

What can Status Studio do?

Schedule WhatsApp statuses from a queue, watched folder or albums, with templates and optional AI-written text. Quiet hours and posting limits help control the schedule. It starts off and in dry run; you must accept the notice and enable live posting yourself.

Can I read or export my messages?

Yes. Browse saved conversations in the app, search message text and export readable HTML transcripts. The message data is stored in a local SQLite database.

PRIVACY & SUPPORT

Make an informed choice.

Is this an official WhatsApp, OpenAI or Google app?

No. WhatsBackUp is independent and unofficial. Linked services can restrict unofficial access or change their interfaces. Review the relevant account terms and the app’s notices before connecting.

Does it upload my content to WhatsBackUp?

There is no WhatsBackUp account or archive-hosting service. Linked sources, your chosen cloud software and any enabled AI provider use their own services. Optional Status Studio posts to your WhatsApp account. See the privacy page for each data flow.

Where is my API key stored?

The Windows app protects provider keys with Windows data protection. They are sent to the provider endpoint you configure when requests are made. Review any custom endpoint before saving it.

What if I archive other people’s information?

Use chat exclusions and media settings to limit what you keep. Respect other people’s privacy and any obligations that apply to your use. Be careful when exporting or sharing an archive.

Where can I get help?

Use Contact for a question or GitHub issues for a reproducible bug. Include your app version and the source affected; review diagnostics before sharing.
