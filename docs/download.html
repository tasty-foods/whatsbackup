§ 00 This release

New in 1.3.1 — it sorts on your own PC, and says what it found

Existing installations update themselves on the next restart.

Sorting runs on this computer, for nothing
Every free allowance runs out. A model on your own machine does not, and it needs no account and no API key. Point the sorting at Ollama and it reads your photographs locally — no quota, no daily reset, and nothing leaves the PC. Pictures are sent at a size worth sending: a phone photo cost 4,046 tokens and 143 seconds at full resolution, and 1,067 tokens and 24 seconds at 1024 pixels, with the prices on a spec sheet still legible. That smaller bill is charged to paid providers too.
A search finds what a conversation was about
The sorting had been reading every chat and writing down what it was about, and none of it was searchable. Asking for ice cream machine found one message that happened to contain the words and missed the three suppliers whose conversations were entirely about buying one. Both questions are asked now and the answers kept apart: which conversations are about this, then which messages say it.
An overview of what it found
The app opens on what the sorting produced — the counts, then every project it discovered, largest first, with what it decided each one was and the people in it. A card is a way in: a project opens its conversations, an album opens its pictures.
The words it chose, as filters
Labelling invents its own vocabulary, and it was reachable only by guessing a word and typing it. The commonest tags now sit above the gallery as one-click chips with their counts, and all of them are in the filter menu — built by counting what is actually on the photographs, so the list grows as more are read.
Status Studio shows its own brakes
The scheduler has always enforced a daily cap, a minimum gap, a catch-up window and quiet hours. There was no way to see or change any of them. There is now, alongside the drop folder and the footer. Something that posts publicly under your own name should not keep its limits to itself.
Fixes
A model without schema support was handed the JSON schema itself and told to match it, and copied it back instead of filling it in — every label came out empty. The connection test called a model blind when it answered #ff0000 to a red square, and a blind provider has every photograph skipped in silence. A local model that was not running failed each item three times instead of being stepped past. A photographed page was transcribed until the reply was cut off mid-word, which is not valid JSON, so the item failed for being too informative. And grouping is no longer attempted when the library cannot fit the model’s context: what does not fit is dropped silently, and albums built from the last tenth of an archive are worse than none.

§ 01 Installation

Five steps, start to finish

  1. 01

    Run the installer

    Double-click WhatsBackUp-Setup-1.3.1.exe. There is nothing to install beforehand — no Node.js, no Chrome, no developer tools. The app carries everything it needs.

  2. 02

    Get past the blue warning

    Windows will most likely say "Windows protected your PC". That is expected: the installer is not signed with a paid certificate, so Windows does not recognise the publisher. It says nothing about whether the app is safe. Click More info, then Run anyway.

    Your antivirus may flag it once too. The app carries its own copy of Chrome — that is how it talks to WhatsApp Web — and "an app with a browser inside it that reads messages" looks suspicious to a scanner on sight. If it gets quarantined, restore it and allow it.

  3. 03

    Answer four short questions

    A notice to read and accept; where to keep your media; optionally a cloud folder — pCloud, OneDrive, Dropbox or a network drive — so videos sync off the PC by themselves; and whether it starts with Windows. Recommended, since it only captures while running.

  4. 04

    Scan the QR code

    On your phone: WhatsApp → Settings → Linked devices → Link a device, then scan the code on screen. Exactly the flow you know from WhatsApp Web. From that moment, everything you send or receive is kept automatically.

  5. 05

    Pull in what you already have

    Open ⚙︎ Settings → History → Import history now. It walks your existing chats and downloads the media WhatsApp still holds — frequently years of photographs. Anything WhatsApp has already deleted is reported as skipped rather than silently missed.

§ 02 Requirements

What you need

Operating system
Windows 10 or Windows 11, 64-bit
Disk space
About 600 MB for the app, plus room for your media
Administrator rights
Not needed — it installs for your user alone
Other software
None
A phone
The one your WhatsApp account runs on, for the single QR scan
An account with us
There isn't one
Updates install themselves
It checks GitHub for new releases and updates quietly in the background. Keep that on: when WhatsApp changes its site and breaks capture, an update is how the fix reaches you.
Uninstalling leaves your files
Remove it from Apps & features and every photograph, video and message stays exactly where it is. Ordinary files in ordinary folders — nothing is locked inside the app.
Rather build it yourself?
Reasonable — it is a stranger's unsigned binary that reads your messages. The full source is public: clone it, read it, then npm install and npm run dist produce the same installer.
If something goes wrong
⚙︎ Settings → App → Copy diagnostic report gathers everything useful into the clipboard. Your API key is never in it.

§ 03 Disclosure

Before you install

  1. This is not an official WhatsApp app. It connects the way WhatsApp Web does, through an open-source library WhatsApp does not endorse. Their terms do not permit unofficial clients, and there is a real if small chance an account gets limited or banned for using one. If that risk is unacceptable to you, don't install it.
  2. It archives other people's media too. Everything sent to you is kept, and none of the senders agreed to that. Keep the copies to yourself.
  3. It only captures while it is running. Anything arriving with the app closed is missed at the time, though Import history can usually collect it afterwards.
