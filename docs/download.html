Before you install

A few practical things.

  • A Windows PC: the app captures and imports while it is running.
  • Your own accounts: link WhatsApp with a QR code; sign in separately for ChatGPT or Gemini.
  • An unsigned installer: Windows may display a publisher warning. Download only from this project’s GitHub release.
  • An unofficial tool: service changes can interrupt imports. Review the in-app notices before linking accounts.

SETUP

From download to your first import.

  1. 01

    Download the installer

    Use the button above to get the Windows installer from GitHub. No Node.js or developer tools are needed. If the download does not start, use the latest release page.

  2. 02

    Review the Windows prompt

    The installer is unsigned, so Windows may show “Windows protected your PC.” Check that the file came from the linked GitHub release before deciding whether to continue via More info → Run anyway. If security software reports a specific threat, investigate the report before proceeding.

  3. 03

    Choose where to keep your files

    Follow setup to accept the notice, choose a media folder, optionally add a cloud folder and decide whether to start with Windows. You can change these choices later in Settings.

  4. 04

    Link a source

    For WhatsApp, open Linked devices → Link a device on your phone and scan the app’s QR code. For ChatGPT or Gemini, use the source connection controls and sign in in the window that opens.

  5. 05

    Import available history

    Run a history import for the source you connected. The overview shows progress and the result, including skipped or failed items. Browse your archive, then check any media copies in your cloud folder.

HELP

Already installed?

How do updates work?

The installed app checks GitHub for newer releases. Keep updates enabled so fixes to source connections can reach you. The website download is also updated from the latest published release when GitHub is reachable.

Will uninstalling remove my archive?

Uninstalling leaves the saved media and local data in place. To remove everything, also remove the app’s data folder, chosen media folders and any copies in your cloud storage. See the privacy page for the locations.

An import failed. What should I send with a report?

Include the app version, the source and the error wording. In Settings → App, use Copy diagnostic report, then review the text before sharing it through Contact or GitHub issues.
