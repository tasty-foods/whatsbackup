Installation

Five steps, start to finish

  1. Run the installer

    Double-click WhatsBackUp-Setup-1.1.0.exe. There is nothing to install first — no Node.js, no Chrome, no developer tools. The app carries everything it needs.

  2. Get past the blue warning

    Windows will probably say "Windows protected your PC". That is expected: the installer is not signed with a paid certificate, so Windows does not recognise the publisher yet. It says nothing about whether the app is safe. Click More info, then Run anyway.

    Your antivirus may also flag it once. The app carries its own copy of Chrome — that is how it talks to WhatsApp Web — and "an app with a browser inside it that reads messages" looks suspicious to a scanner on sight. If it gets quarantined, restore it and allow it.

  3. Answer four short questions

    A notice to read and accept; where to keep your media; optionally a cloud folder (pCloud, OneDrive, Dropbox or a network drive) so videos sync off the PC by themselves; and whether it should start with Windows. Recommended, since it only captures while it is running.

  4. Scan the QR code

    On your phone: WhatsApp → Settings → Linked devices → Link a device, then scan the code on screen. Exactly the flow you already know from WhatsApp Web. From this moment, every photo and video you send or receive is saved automatically.

  5. Pull in what you already have

    Open ⚙︎ Settings → History → Import history now. It walks your existing chats and downloads the media WhatsApp still holds — often years of photos. Anything WhatsApp has already deleted from its servers is reported as skipped rather than silently missed.

Updating and removing

Updates install themselves. WhatsBackUp checks GitHub for new releases and updates quietly in the background. Keep that switched on — when WhatsApp changes its website and breaks capture, an update is how the fix reaches you.

Uninstalling leaves your files alone. Remove it from Windows' Apps & features list and every photo, video and message it saved stays exactly where it is. They are ordinary files in ordinary folders — nothing is locked inside the app.

Rather build it yourself?

Reasonable. It is a stranger's unsigned binary that reads your messages. The full source is on GitHub — clone it, read it, and run npm install && npm run dist to produce the same installer.

Please read this before installing

  • This is not an official WhatsApp app. It connects the way WhatsApp Web does, using an open-source library WhatsApp does not endorse. WhatsApp's terms do not permit unofficial clients, and there is a real if small chance an account gets limited or banned for using one. If that risk is unacceptable to you, do not install it.
  • It saves other people's media too. Everything sent to you is archived, and the senders never agreed to that. Keep the copies to yourself.
  • It only captures while it is running. Anything arriving while the app is closed is missed, though Import history can usually pick it up afterwards.
