Welcome to WhatsBackUp

Save WhatsApp messages and selected media on this PC. You can also copy media to your cloud folder and import images from ChatGPT or Gemini.

Before you start, three things worth knowing:

  • This connects to WhatsApp the same way WhatsApp Web does, but it is not an official WhatsApp app. WhatsApp's terms don't allow unofficial clients, and there is a real if small chance an account gets limited or banned for using one.
  • It saves media from everyone you chat with, and they haven't agreed to that. Keep the copies to yourself.
  • Everything stays on this computer and your own cloud folder. There is no account, no server of ours, and no telemetry. The one exception is switched off: AI sorting can send photos and message text to an AI provider you choose, and it will not send anything until you turn it on and accept a second notice that shows you the exact data first.

Bring across your existing copies?

An earlier version of this app was found on this PC. Its media, messages and WhatsApp link can be imported so you don't start over — or scan again.

Where should your media be saved?

Photos and videos can add up to a lot of space, so pick somewhere with room.

Also copy to a cloud folder?

If you use pCloud, OneDrive, Dropbox or a network drive, choose a folder inside it. Media is copied there; your cloud app handles the upload. Message text remains on this PC.

Google Photos Preview

Keep a copy of photos and videos from your Google Photos timeline in this library. Choose Connect, sign in with Google in the window that opens, then choose Import now.

…

Downloads the files Google Photos offers, with duplicate detection. Large libraries can take hours; you can stop and run again to skip files already saved. Dates use Google’s photo label when readable, otherwise the import date. Original file metadata is kept.

This uses the Google Photos website, so changes to that website can interrupt imports. Only the main timeline is read; archived photos, Locked Folder, trash and photos only in shared albums are excluded. Sync copies files into WhatsBackUp; it does not upload or delete anything in Google Photos.

Pulls media and message history already in your chats, as far back as WhatsApp lets a linked device see. Safe to run anytime — anything already saved is skipped.

Last import: never

Older media often can't be downloaded any more — WhatsApp removes files from its servers after a while. Those are reported as skipped, not lost by this app.

Find files by what is inside them

Describe a photo, search text inside a document, or find a moment in a video. The index saves those details on your PC. Your chosen AI service reads photos and sampled video frames, and transcribes scanned document pages. Text documents are read locally.

What leaves this PC

Preview examples of the data used. Visual indexing sends resized photos, sampled video frames or scanned pages. AI search sends your query and short excerpts from candidate matches; album sorting sends brief descriptions.
